## 本机运行与换机注意

现有验证环境为 Windows、Python 3.12.10。照片依赖 Pillow，原页渲染依赖当前 Python 的 PyMuPDF；Word 使用独立文档 Python 及 python-docx／Pillow，不是全部仅依赖标准库。

在项目根目录运行：

```powershell
python -X utf8 scripts/road.py --help
python -X utf8 scripts/road.py --doctor
```

所有请求包括 `--doctor`、`resume`、`delivery-check` 都会先执行既定过期清理；检查逻辑不改写有效咨询，不表示整次调用无清理副作用。隔离开发检查用自有仓库外 `--store`，不要指向真实咨询目录。

换机时将 `config.example.json` 复制为仓库外本机配置，用 CLI `--config` 指定：

| 配置／参数 | 当前行为 |
|---|---|
| `spec_skill` | 默认 `C:/Users/Seven/Desktop/guifanchaxun/tools/guifan-chaxun`；复用已有可读源库，不修改原项目 |
| `tool_timeout_seconds` | 上游查询超时，默认 45 秒 |
| `document_python` | 可选绝对路径；默认当前用户 `.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe`；缺失时报错，不自动安装 |
| `privacy_default` | 示例中的该键未被代码读取；实际新咨询默认 restricted／不允许模型读取，不能靠此键授权 |
| `--store` | 仓库外本地目录；默认 `%LOCALAPPDATA%/RoadMaintenanceExpert/<项目绝对路径哈希前12位>` |

移动项目可能产生新的默认存储键，不代表原记录丢失。保留经文件身份验证的 Windows 合并目录视图，不自动搬移或切换到单个缓存目录。集成脚本尚无统一 `--config` 接口，部分依赖根目录示例配置；换机时逐项核对，不能以 CLI 配置成功代替全部检查通过。

## 验证与交付

在项目根目录执行；每次交付记录本轮结果，不沿用历史通过结论：

| 命令 | 范围及影响 |
|---|---|
| `python -X utf8 scripts/check_docs.py` | 只读检查本地 Markdown 链接／锚点、代码围栏及交接版本与来源一致性；不访问咨询库或联网 |
| `python -X utf8 -m unittest discover -s tests -v` | 合成单元与回归 |
| `python -X utf8 scripts/check_local.py` | 真实本地规范查询／回源／渲染与合成咨询；只比较选定上游文件指纹 |
| `python -X utf8 scripts/check_trial.py` | 先按既定策略清理默认库过期状态，校验剩余记录；其余问答／恢复／导出／备份在合成目录 |
| `python -X utf8 scripts/check_advice.py` | 分领域分析、专项导出、过时拒绝及生命周期 |
| `python -X utf8 scripts/check_media_delivery.py` | 合成图片、比较、各类 Word、原图保护和副本清理；不自动渲染查看 |
| `python -X utf8 scripts/check_delivery.py` | 交付检查、文字疑点、历史标注、内容／范围绑定和 Word 校验 |

五套集成默认删除自身合成目录，返回 `artifacts_retained=false`。需要排版检查时，媒体检查可用 `--qa-dir` 指定新的仓库外目录保留合成文件，再实际渲染逐页查看。没有渲染或真人交互就保留未验证，不能用历史查看代替本轮验证。
