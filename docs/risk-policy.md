# 风险筛查规则与边界

版本0.1.0-draft，专业审核 pending。规则是产品需求驱动的无数值关注清单，不是法定分级。

| key | 方向 | 意图 |
|---|---|---|
| sudden_collapse | 突发或道路塌陷 | 不以规模小、未扩大自动消除关注 |
| progression | 持续扩大、变形或滑移 | 区分当前、历史、否定和未知 |
| active_fall | 正在落石、掉块或滑塌 | 不要求进入危险部位补图 |
| bridge_deformation | 异常变形、变位或振动 | 不作正式结构结论 |
| traffic_affected | 影响或威胁通行 | 优先报告与核查 |

存在当前、非系统推测的正向征兆即 attention。矛盾保留，正向信息不被一句否认冲掉。相关未知保持 undetermined；明确完整的相关否认、routine=true 且无冲突才可普通咨询，仍非安全评估。

文字规则只是提示，跨句时间、否定、隐喻、口语和复杂转折可能误读。宿主需回原话并补结构化观察；未命中不等于安全，系统推测不能支持降级。

纠正需同类 supersedes、用户标记及理由，保留原记录。每轮重新筛查，新信息后旧答案标过时；状态变化不能签发恢复通行或解除控制。

15个显式合成情境及冲突、纠正、多轮等检查只证明对应行为，不能证明真实识别率；实际依赖前需相应专业复核。
