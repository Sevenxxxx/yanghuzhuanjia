# ADR 0001：现有 Codex 承载个人版

日期：2026-10-20。依据已确认 v1.2 路线实施。

用项目 Skill 与 Python 标准库 CLI，不建 Agent 循环、模型服务、数据库或网页。客户端分析，工具实现可测试的状态与证据行为。

规范固定操作适配，原目录只读，图像写仓库外。案例 JSON 单源和派生索引，允许空库。知识卡用 JSON 以便 briefing 携带审阅状态；这是格式选择，不改变知识审核要求。

咨询存储在 LOCALAPPDATA 下按项目隔离，版本快照、指纹、乐观版本和写锁保护记录。更复杂事务不在个人版范围。

权限关口仅控制 CLI 输出与调用，不能全面控制宿主；P3 再接受控服务。资产可迁移，但不保证换模型后结果一致。专业审核和真实结果缺少时如实保留，不把候选、合成或自我生成内容提升为工程证据。

本 ADR 记录初始技术取舍；后续功能依赖和模块职责以 [当前架构](../architecture.md) 及 [运行环境](../交接.md#本机运行与换机注意) 为准，不将当时“标准库 CLI”推定为所有现有功能均只依赖标准库。
